# Nguồn tài nguyên (Asset credits)

Toàn bộ tài nguyên trong thư mục này là **miễn phí, dùng được cho mục đích thương mại**.
Không có sprite nào được lấy từ Flappy Bird hay game thương mại khác.

## Hình ảnh (`sprites/`) — Kenney (CC0)

| Thư mục | Pack gốc | Trang tải |
|---|---|---|
| `sprites/` (nền, đất, đá, sao, khói) | Tappy Plane 1.1 | https://kenney.nl/assets/tappy-plane |
| `sprites/planes`  | Tappy Plane 1.1 | như trên |
| `sprites/ui`      | Tappy Plane 1.1 | như trên |
| `sprites/numbers`, `sprites/letters` | Tappy Plane 1.1 | như trên |

Giấy phép gốc: *"License: (Creative Commons Zero, CC0) — You can use this content for
personal, educational, and commercial purposes."* Tên file giữ nguyên như trong pack.

## Âm thanh (`audio/`) — Kenney (CC0)

| File | Nguồn |
|---|---|
| `score.ogg` (pepSound1), `star.ogg` (powerUp2), `gameover.ogg` (lowThreeTone), `level_up.ogg` (phaserUp3) | Kenney — Digital Audio — https://kenney.nl/assets/digital-audio |
| `new_best.ogg` (jingles_PIZZI01) | Kenney — Music Jingles — https://kenney.nl/assets/music-jingles |
| `flap1.ogg`, `flap2.ogg` (cloth1, cloth2) | Kenney — RPG Audio — https://kenney.nl/assets/rpg-audio |
| `hit.ogg` (impactPunch_heavy_000) | Kenney — Impact Sounds — https://kenney.nl/assets/impact-sounds |
| `select.ogg`, `confirm.ogg`, `pause.ogg` (select_001, confirmation_001, switch_001) | Kenney — Interface Sounds — https://kenney.nl/assets/interface-sounds |

Các file đã được đổi tên theo vai trò trong game, nội dung giữ nguyên.
Ghi công (không bắt buộc với CC0 nhưng tác giả mong muốn): Kenney (www.kenney.nl).
